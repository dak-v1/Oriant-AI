# Oriant.ai product mock — 4–6 minute demo script

Canonical walkthrough (spec Appendix C) using the BrightPath Home Services demo
company. Reset first: top bar → sliders icon → **Reset demo**.

| # | ~Time | Where | Do this | Say this |
|---|---|---|---|---|
| 1 | 0:00 | Landing `/` | Click **Start Free Discovery** | "Everything after this click is the product." |
| 2 | 0:15 | Onboarding | Click **Use demo company**, pick **Assist** mode | "Assist keeps every important action human-reviewed." |
| 3 | 0:40 | Onboarding | Skim the tools step (pre-selected), Continue | "Selecting a tool isn't connecting it — that comes later." |
| 4 | 1:00 | Lean Canvas | Choose **Build it with Oriant**, answer the first card by voice, click **Improve wording with AI**, Accept | "Voice-first, never voice-only — and AI never overwrites my words." |
| 5 | 1:30 | Lean Canvas | Use the header demo menu → Fast-forward → **Discovery interview** (fills the canvas) | — |
| 6 | 1:40 | Discovery | **Start speaking** on Q1, watch waveform → transcript, **Confirm** | "The transcript is editable before anything is saved." |
| 7 | 2:00 | Discovery | Open **What Oriant knows** mid-call — point at provenance chips + the floating call bar; Return to call, confirm Q2 | "Every fact shows where it came from — owner-confirmed vs assumption." |
| 8 | 2:20 | Discovery | Fast-forward → **Report review**; on the report, Confirm one section, Edit another | "This is Gate 1 — nothing is planned until I approve this document." |
| 9 | 2:45 | Report | **Approve and send to Planner** → watch the 5-stage generation | "Company Report v2 — Approved is now immutable." |
| 10 | 3:10 | Planner | Point out 3 preset agents + the custom Service Recovery Coordinator; click a connector path | "Tier 1 is matched from the library; Tier 2 is designed from scratch." |
| 11 | 3:30 | Planner | Open the custom agent → answer one design question by voice → Approve design | "The custom agent gets its own mini discovery." |
| 12 | 3:55 | Planner | In the command bar: "Keep campaign publishing human-approved" → watch the change + **Undo** → redo it | "Plain English reconfigures the plan — deterministically, with undo." |
| 13 | 4:15 | Integrations | Connect **Gmail** through the wizard | "Plain-language permissions; the technical scopes hide under Advanced." |
| 14 | 4:30 | Planner | **Confirm workforce plan** → readiness checklist → approve | "Gate 2 — the plan can't ship until every agent is ready." |
| 15 | 4:45 | Build | Watch two job cards stream logs; open **Review generated package** → YAML tab | "Simulated build, real artifacts to review." |
| 16 | 5:05 | Sandbox | Run the high-value complaint scenario → at the pause, edit the resolution, **Approve and resume** | "The agent stopped itself — compensation always waits for a human." |
| 17 | 5:30 | Deploy | Tick the acknowledgements → **Activate workforce** | "Agents go live one by one." |
| 18 | 5:45 | Workspace | Open **Approvals**: Review the $180 refund → **Ask Agent to Update** → Approve; point at the calendar pill updating | "Card, calendar and activity update together." |
| 19 | 6:00 | Workspace | ⌘K → "Prepare a summary of overdue invoices" | "One command bar for the whole workforce — routed by the Orchestrator." |

Fallbacks: every timed animation has a **Skip animation** control; the demo menu
can fast-forward to any phase; refresh never loses progress (localStorage);
**Reset demo** returns to a clean state.
